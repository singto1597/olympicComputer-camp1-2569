# หาค่าน้อยที่สุดและมากที่สุด - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `findMaxAndMin` ในไฟล์ `find_max_and_min.cpp` และเก็บไฟล์ `find_max_and_min.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

บน Linux สามารถคอมไพล์ด้วยคำสั่ง `sh compile.sh` หรือใช้คำสั่งต่อไปนี้โดยตรง:

```sh
g++ -std=c++17 -O2 grader.cpp find_max_and_min.cpp -o find_max_and_min
```

บน Windows สามารถคอมไพล์ด้วยคำสั่ง:

```bat
g++ -std=c++17 -O2 grader.cpp find_max_and_min.cpp -o find_max_and_min.exe
```

## รูปแบบข้อมูลของโปรแกรมตรวจตัวอย่าง

- บรรทัดแรกประกอบด้วยจำนวนเต็มบวก $Q$ แทนจำนวนครั้งที่เรียกฟังก์ชัน
- จากนั้นสำหรับแต่ละครั้งที่เรียก (ตั้งแต่ครั้งที่ $1$ ถึง $Q$):
  - บรรทัดแรกประกอบด้วยจำนวนเต็มบวก $N$ แทนจำนวนสมาชิกในเวกเตอร์ $A$
  - บรรทัดถัดไปประกอบด้วยจำนวนเต็ม $N$ ค่า คือ $A[0], A[1], \dots, A[N-1]$

โปรแกรมตรวจตัวอย่างจะพิมพ์ผลลัพธ์ของแต่ละครั้งที่เรียกออกมาบรรทัดละหนึ่งครั้ง โดยแต่ละบรรทัดประกอบด้วยค่าน้อยที่สุดและค่ามากที่สุดคั่นด้วยช่องว่าง

## ข้อควรระวัง

โปรแกรมตรวจจะเรียกฟังก์ชัน `findMaxAndMin` หลายครั้งภายในการรันโปรแกรมเดียวกัน แต่ละครั้งที่เรียกถือเป็นกรณีทดสอบอิสระจากกัน ผลลัพธ์ของแต่ละครั้งต้องขึ้นกับเวกเตอร์ $A$ ของการเรียกครั้งนั้นเท่านั้น ระวังการใช้ตัวแปรส่วนกลาง (global variable) หรือตัวแปรสแตติก (static variable) ที่ไม่ได้ถูกกำหนดค่าใหม่ (reset) ซึ่งอาจทำให้ข้อมูลจากการเรียกครั้งก่อนส่งผลกระทบต่อการเรียกครั้งถัดไป

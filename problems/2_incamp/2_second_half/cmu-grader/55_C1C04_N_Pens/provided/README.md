# หยิบปากกา - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชันทั้งสองในไฟล์ `n_pens.cpp` และเก็บไฟล์ `n_pens.h` ไว้โดยไม่แก้ไข
ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูล
ไปยังเอาต์พุตมาตรฐาน บน Linux ให้คอมไพล์ด้วยคำสั่ง `sh compile.sh` หรือใช้คำสั่ง
ต่อไปนี้โดยตรง

```sh
g++ -std=c++17 -O2 grader.cpp n_pens.cpp -o n_pens
```

## รูปแบบข้อมูลของโปรแกรมตรวจตัวอย่าง

บรรทัดแรกประกอบด้วย `N K` จำนวนเต็มที่เหลือคือจำนวนปากกาที่คู่แข่งจะหยิบ
เรียงตามลำดับ โปรแกรมตรวจตัวอย่างจะอ่านหนึ่งค่าต่อหนึ่งตาของคู่แข่งและจำลองเกม
ทุกตาจนจบ ค่าที่เหลือหลังเกมจบจะไม่ถูกนำมาใช้

โปรแกรมพิมพ์ `1` เมื่อผู้เข้าแข่งขันชนะ และพิมพ์ `0` เมื่อผู้เข้าแข่งขันแพ้หรือ
ฟังก์ชันของผู้เข้าแข่งขันคืนค่าที่ผิดกติกา หากไม่มีค่าการหยิบของคู่แข่งเพียงพอ
หรือค่าดังกล่าวผิดกติกา โปรแกรมจะรายงานข้อผิดพลาดทางเอาต์พุตข้อผิดพลาดมาตรฐาน
และจบการทำงานด้วยรหัส `2`

ตัวอย่างเช่น ข้อมูลที่มี `6 2` ในบรรทัดแรกและ `1 1` ในบรรทัดถัดไปจะให้ผลลัพธ์
เป็น `1` เมื่อใช้คำตอบที่ถูกต้อง คู่แข่งในโปรแกรมตรวจตัวอย่างเดินตามค่าที่ระบุไว้
จึงใช้สำหรับทดลองตัวอย่างเท่านั้น และไม่ใช่คู่แข่งที่เล่นอย่างดีที่สุดในโปรแกรมตรวจจริง
คู่แข่งในโปรแกรมตรวจจริงจะรักษาวิธีบังคับชนะไว้เสมอเมื่อทำได้ และอาจเลือกการเดิน
ที่ถูกกติกาแบบใดก็ได้เมื่อไม่สามารถบังคับชนะได้

โปรแกรมเรียก `choose_turn(N, K)` หนึ่งครั้งก่อนเรียก `take_pens` ทุกครั้ง ค่า `K`
ไม่เปลี่ยนแปลงระหว่างเกม การเรียก `take_pens` ทุกครั้งเป็นส่วนหนึ่งของเกมเดียวที่
จำลองครบทุกตา แม้คำตอบของผู้เข้าแข่งขันจะไม่ถูกต้อง โปรแกรมจะเรียก `take_pens`
ไม่เกิน $\lceil N/2\rceil$ ครั้ง และทุกปัญหาย่อยเรียกไม่เกิน `100000` ครั้ง
โปรแกรมตรวจจะไม่ข้ามสถานะหรือตาใดของเกม

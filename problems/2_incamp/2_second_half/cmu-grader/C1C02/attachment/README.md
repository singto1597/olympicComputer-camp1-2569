# แลกเงิน - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `exchange` ในไฟล์ `exchange.cpp` และเก็บไฟล์ `exchange.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

บน Linux สามารถคอมไพล์ด้วยคำสั่ง `sh compile.sh` หรือใช้คำสั่งต่อไปนี้โดยตรง:

```sh
g++ -std=c++17 -O2 grader.cpp exchange.cpp -o exchange
```

บน Windows สามารถคอมไพล์ด้วยคำสั่ง:

```bat
g++ -std=c++17 -O2 grader.cpp exchange.cpp -o exchange.exe
```

## รูปแบบข้อมูลของโปรแกรมตรวจตัวอย่าง

- บรรทัดแรกประกอบด้วยจำนวนเต็มบวกสองจำนวน คือ $X$ และ $N$ แทนจำนวนเงินที่ต้องการแลก และจำนวนชนิดของธนบัตรตามลำดับ คั่นด้วยช่องว่าง
- บรรทัดที่สองประกอบด้วยจำนวนเต็มบวก $N$ จำนวน คือ $A[0], A[1], \dots, A[N-1]$ แทนมูลค่าของธนบัตรแต่ละชนิด เรียงจากมากไปน้อย คั่นด้วยช่องว่าง

โปรแกรมตรวจตัวอย่างจะพิมพ์ผลลัพธ์ออกมาหนึ่งบรรทัด ประกอบด้วยจำนวนเต็ม $N$ จำนวน คือจำนวนธนบัตรของแต่ละชนิดที่ใช้ในการแลกเงิน เรียงลำดับตามชนิดธนบัตรในเวกเตอร์ $A$ คั่นด้วยช่องว่าง

## ข้อควรระวัง

- โปรแกรมตรวจจะเรียกฟังก์ชัน `exchange` หนึ่งครั้งต่อหนึ่งกรณีทดสอบ
- เวกเตอร์ผลลัพธ์ที่ส่งคืนต้องมีขนาดเท่ากับ $N$ พอดี และสมาชิกแต่ละตัวต้องเป็นจำนวนเต็มที่ไม่เป็นลบ
- เนื่องจากจำนวนเงิน $X$ และมูลค่าของธนบัตร $A[i]$ อาจมีค่าสูงถึง $10^{18}$ ผู้เข้าแข่งขันควรใช้ชนิดข้อมูล `long long` เพื่อป้องกันปัญหาการล้นของจำนวนเต็ม (integer overflow)

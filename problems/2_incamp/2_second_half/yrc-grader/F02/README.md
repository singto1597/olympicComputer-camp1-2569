# ชนิดของอักขระ - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `charKind` ในไฟล์ `char_kind.cpp` และเก็บไฟล์ `char_kind.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./char_kind < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีอักขระ c หนึ่งตัว

อักขระที่ฟังก์ชันคืนกลับ บรรทัดละหนึ่งตัว

# ลูกบาศก์บวกค่าสัมบูรณ์ - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `cubeAbs` ในไฟล์ `cube_abs.cpp` และเก็บไฟล์ `cube_abs.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./cube_abs < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีจำนวนเต็ม x หนึ่งค่า (ค่าของ x ในการเรียกครั้งนั้น)

ค่าที่ฟังก์ชันคืนกลับ บรรทัดละหนึ่งค่า

# หารแล้วเหลือเศษ - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `divMod` ในไฟล์ `div_mod.cpp` และเก็บไฟล์ `div_mod.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./div_mod < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีจำนวนเต็ม a และ b คั่นด้วยช่องว่าง

สำหรับแต่ละครั้งที่เรียก โปรแกรมตรวจจะพิมพ์ค่า q และ r (ที่ฟังก์ชันกำหนดไว้) คั่นด้วยช่องว่าง บรรทัดละครั้ง

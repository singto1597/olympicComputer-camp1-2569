# กระปุกออมสิน - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `piggyBank` ในไฟล์ `piggy_bank.cpp` และเก็บไฟล์ `piggy_bank.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./piggy_bank < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีจำนวนเต็ม op และ x คั่นด้วยช่องว่าง (การเรียกฟังก์ชันตามลำดับ)

ค่าที่ฟังก์ชันคืนกลับสำหรับแต่ละครั้งที่เรียก บรรทัดละหนึ่งค่า

# แปลงเลขฐาน - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `toBase` ในไฟล์ `to_base.cpp` และเก็บไฟล์ `to_base.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./to_base < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีจำนวนเต็ม n และ b คั่นด้วยช่องว่าง

ข้อความที่ฟังก์ชันคืนกลับ บรรทัดละหนึ่งค่า

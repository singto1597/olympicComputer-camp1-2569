# เลื่อนอาร์เรย์ไปทางซ้าย - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `rotateLeft` ในไฟล์ `rotate_left.cpp` และเก็บไฟล์ `rotate_left.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./rotate_left < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- สำหรับแต่ละครั้งที่เรียก:
- บรรทัดแรกมีจำนวนเต็ม N และ k
- บรรทัดถัดไปมีจำนวนเต็ม N ค่า คือ A[0], A[1], ..., A[N − 1]

หลังเรียกฟังก์ชัน โปรแกรมตรวจจะพิมพ์ค่าในเวกเตอร์ A ทั้งหมดคั่นด้วยช่องว่าง บรรทัดละครั้ง

คู่มือ Tools กับ Grader

สคริปต์ใน tools/ มีน้อยพอจำได้ แต่เวลาลืมก็ลืมจริง ๆ หน้านี้รวมว่าตัวไหนทำอะไร รันยังไง และ grader หลายตัวแยกกันยังไง

  • 3 สคริปต์ที่ต้องรัน
  • 6 contest
  • โจทย์โหลดมือ
  • ไม่มีรหัสเก็บใน repo
01

อยากทำอะไร ใช้ตัวไหน

สามบรรทัดนี้คือทั้งหมดที่ต้องจำ

  • โหลด PDF มาแล้ว อยากให้เข้าโฟลเดอร์เป็นระเบียบสร้าง .cpp จาก template ให้ด้วย fish tools/organize.fish ~/Downloads --cpp
  • ได้คะแนนแล้ว อยากอัปเดตตาราง + ย้ายข้อที่เต็มย้ายเข้า _done/ แล้วสร้าง README ใหม่ python3 tools/sync_done.py
  • อยากรู้ว่ายังขาดข้อไหนอ่านอย่างเดียว ไม่แก้อะไร python3 tools/find_missed.py

โจทย์ทุกข้อโหลดมือจาก cs.science.cmu.ac.th/compo — ไม่มีสคริปต์ล็อกอิน ไม่มีรหัสผ่านเก็บไว้ที่ไหนในโปรเจกต์

02

แต่ละตัวทำอะไร

organize.fish

fish · ตัวที่ใช้บ่อยที่สุด

ไฟล์ที่โหลดมาชื่อมักรก — โจทย์ สอวน (th).pdf — มันจะสร้างโฟลเดอร์ชื่อสะอาดให้ แล้วย้ายไฟล์เข้าไป ตัดวงเล็บทิ้ง แทนเว้นวรรคด้วย _ ส่วนชื่อไทยเก็บไว้ครบ

fish tools/organize.fish ~/Downloads --dry-run # ดูเฉย ๆ ยังไม่ย้าย fish tools/organize.fish ~/Downloads --cpp # ย้าย + สร้าง .cpp fish tools/organize.fish docs/sheets --prefix 20261005_AM

ถ้าโหลด Statement มาแล้วชื่อเป็นรหัสโจทย์อยู่แล้ว (C1PC01.pdf) จะได้โฟลเดอร์ 01_C1PC01_Alice_and_Bob/ พร้อม C1PC01.pdf กับ C1PC01.cpp ข้างใน — ลำดับ+ชื่อโจทย์ดึงจาก tools/scores/*.txt ส่วนไฟล์ข้างในคงชื่อรหัสเปล่า ๆ ตามที่ grader บังคับตอน submit · รหัสที่ยังไม่มีในไฟล์คะแนนจะได้โฟลเดอร์ชื่อรหัสตามปกติ

sync_done.py

python · ตัวหลักหลังได้คะแนน

อ่านตารางคะแนนทุกไฟล์ใน tools/scores/ ข้อไหนได้เต็มก็ย้าย เข้า _done/ ของโฟลเดอร์นั้น แล้วสร้างตารางคะแนนใน README.md ใหม่ทั้งบล็อก ปิดท้ายด้วยรายการข้อที่ยังไม่มีโฟลเดอร์

python3 tools/sync_done.py

tools/scores/*.txt คือความจริง — ตารางใน README ห้ามแก้มือ รันซ้ำได้เรื่อย ๆ ข้อที่ย้ายแล้วจะข้าม

find_missed.py

python · อ่านอย่างเดียว

เทียบตารางคะแนนกับโฟลเดอร์จริงในเครื่อง บอกว่าข้อไหนมีในระบบแต่ยังไม่ได้โหลด ไม่แก้อะไรเลย ต่างจาก sync_done

python3 tools/find_missed.py

folder_names.py

python · เติมชื่อโจทย์ในชื่อโฟลเดอร์

เปลี่ยน C1PC01/ → 01_C1PC01_Alice_and_Bob/ โดยดึงชื่อโจทย์และลำดับจาก tools/scores/*.txt ไฟล์ข้างในไม่ถูกแตะ · ปกติไม่ต้องรันเอง เพราะ organize ตั้งชื่อให้ตั้งแต่ตอนจัด

python3 tools/folder_names.py # ดูเฉย ๆ python3 tools/folder_names.py --apply # เปลี่ยนจริง (git mv)

scorelib.py

python · โมดูลกลาง ไม่มี CLI

ไม่ได้รันเอง — สามตัวข้างบนเรียกใช้ร่วมกัน มีหน้าที่อ่านทะเบียน contest อ่านไฟล์คะแนน แปลงชื่อโฟลเดอร์ (folder_name_for / task_id_from_folder) และหารหัสโจทย์เจอโดยเดินทั่ว problems/ ไม่ต้องบอกว่าข้อไหนอยู่ช่วงไหน เพราะรหัสโจทย์ไม่ซ้ำกันอยู่แล้ว

03

Contest มีหลายตัว แยกกันยังไง

เว็บ cs.science.cmu.ac.th/compo มีหลาย contest แต่ละอันเป็น CMS คนละตัว คนละชุดรหัสโจทย์ ทะเบียนอยู่ที่ tools/graders.txt

ชื่อในสคริปต์ → โฟลเดอร์ปลายทาง
ชื่อในสคริปต์ คือ ปลายทาง
precamp พรีแคมป์ (ช่วงนี้อยู่) problems/1_precamp/cmu-grader/
camp1_1 ค่าย 1 ครึ่งแรก problems/2_incamp/1_first_half/cmu-grader/
camp1_2 ค่าย 1 ครึ่งหลัง problems/2_incamp/2_second_half/cmu-grader/
pretest Pretest problems/2_incamp/pretest/
camp1_ex1 สอบครั้งที่ 1 ค่าย 1 problems/2_incamp/exam/ex1/
camp1_ex2 สอบครั้งที่ 2 ค่าย 1 problems/2_incamp/exam/ex2/

อยากเพิ่ม contest ใหม่ = เพิ่ม 1 บรรทัดใน graders.txt กับสร้างไฟล์ใน tools/scores/ — ไม่ต้องแก้สคริปต์เลย
บนเว็บยังมีอีก 4 อันที่ไม่ได้ตั้งไว้: 02_Soft_Study (โจทย์ซ้อม) · 06_sandbox · 12_TA_ONLY (นักเรียนเข้าไม่ได้) · zz_cscmu_coding_challenge23 (ของปี 2023)

YRC เป็น grader คนละเว็บ ไม่ได้อยู่ใน CMS นี้ — โฟลเดอร์ yrc-grader/ จึงมีทั้งครึ่งแรกและครึ่งหลัง ตอนนี้ยังไม่รู้ URL กับรูปแบบตารางคะแนน พอเปิดใช้แล้วถ้าได้ตารางเดียวก็เพิ่ม 1 บรรทัดใน graders.txt ถ้าแยกสองครึ่งก็เพิ่ม 2 บรรทัด

04

ลำดับใช้งานปกติ

วนซ้ำแบบนี้ไปเรื่อย ๆ จนจบค่าย

  1. เปิดเว็บ grader โหลด Statement ที่ยังขาด

    python3 tools/find_missed.py

  2. จัดเข้าโฟลเดอร์ + สร้าง .cpp ให้เลย

    fish tools/organize.fish ~/Downloads --cpp

  3. เขียนโค้ด

    ที่ problems/1_precamp/cmu-grader/13_C1PR01_Test/C1PR01.cpp กด Ctrl+Shift+B ใน VSCode เพื่อ build + run (อ่าน input จาก .run/input.in)

  4. ก็อปตารางคะแนนจากหน้าเว็บ

    วางที่ tools/scores/precamp.txt

  5. ปิดรอบ

    python3 tools/sync_done.py

    ได้เต็มก็เข้า _done/ ให้เอง พร้อมสถานะในตาราง:

    • ได้เต็ม
    • ได้บางส่วน
    • ยังไม่ได้คะแนน

06

กติกาที่ควรจำ

  • อย่าแก้ตารางคะแนนใน README ด้วยมือ — มันสร้างจาก tools/scores/*.txt รัน sync_done.py ทับได้เสมอ
  • อย่าย้ายโฟลเดอร์ที่ได้เต็มเข้า _done/ เอง — ให้ sync_done.py ทำ จะได้ตรงกับตาราง
  • โฟลเดอร์โจทย์เป็น <ลำดับ>_<รหัส>_<ชื่อโจทย์> แต่ไฟล์ข้างในเป็นรหัสเปล่า ๆ — เปลี่ยนชื่อโฟลเดอร์ด้วย folder_names.py อย่า rename มือ (สคริปต์ทั้งชุดอ่านชื่อโฟลเดอร์เป็นคีย์)
  • PDF กับสไลด์เป็นหลักฐานผลงาน — อย่าลบหรือย้ายโดยไม่ถาม
  • ไฟล์ที่คอมไพล์แล้วไม่ขึ้น git (.out, .exe) ส่วนไฟล์รันชั่วคราวอยู่ใน .run/
